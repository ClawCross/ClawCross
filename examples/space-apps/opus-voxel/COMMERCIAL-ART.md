# 方块世界：原创素材与商业化改造计划

## 当前边界

- 引擎来源：OpusMC 固定提交 `ca677140a47e668aeb2cfab65d4b3057f786f25d`，MIT，保留 Jeff 的版权声明与许可证。
- 默认包：自写 Canvas 程序化素材，不包含上游 `assets.js`。它是功能完整的占位包，生物表面、工具细节和容器格位还需要专门美术，不能把它当作已经完成的商业美术。
- 测试包：主机独立文件，默认关闭、不打包；设置页的标注不赋予官方素材商用权。商业发行只使用原创或已核实授权的包。
- 更换贴图不能消除所有问题。角色轮廓、命名、品牌、界面构图及宣传也需独立设计，不能保证只换颜色就不存在第三方权利。

## 原创方向：浮岛工坊

保留方块搭建、探索、采集与制造，视觉改成温暖的矿物玩具：奶油石灰岩、青灰页岩、蓝绿苔藓、陶土木作和发光晶簇。用大色面与清楚的材料结构区别物品，不临摹官方纹理、像素布局或角色皮肤。

| 范围 | 设计与实现 |
|---|---|
| 方块 | 按石材、木材、土壤、植物、矿物、玻璃、液体分类；自写可重复的纹理生成器，统一调色与噪声强度。保留引擎的 16×16 图集接口和透明通道。 |
| 工具与物品 | 单独设计轮廓、握柄与材料等级，不把所有图标画成彩色方块。内部兼容键可保留，显示名与外观使用原创内容。 |
| 生物与玩家 | 设计晶角鹿、苔岩兽、夜行构装等独立角色；同时修改几何模型、UV、皮肤与名称，避免仅给现有标志性角色换色。 |
| 界面 | 原创圆角工具栏、清楚的物品槽、制作箭头与进度条；按引擎真实槽位布置 GUI，不能用随机格子代替。 |
| 字体与品牌 | 主标题使用「方块世界」，自绘标识；默认系统字体，不分发原版字体或 Minecraft 标志。若嵌入字体，单独记录字体许可。 |
| 动画与声音 | 自制液体、火焰、破坏阶段等图集帧；保留自写合成音效，检查是否仍有第三方录音或图像。 |
| 玩法身份 | 围绕浮岛修复、材料研究和 Agent 建造伙伴增加自己的目标与任务，逐步替换原作特定命名和说明。 |

## 实施顺序

1. **先能辨认**：逐类替换地表、矿物、工具和食物，做固定种子的样板场景，覆盖白天、夜晚、水下与透明方块。
2. **再完成交互**：按实际槽位制作物品栏、箱子、熔炉、合成台图像，覆盖手机、宽屏与不同界面缩放。
3. **独立角色与动效**：替换模型和显示名，补齐贴图 UV、行走/攻击、液体与破坏动画。
4. **发行检查**：为每项外部资源记录作者、原始地址、版本、许可和修改；检查 npm/部署产物没有测试素材，保留 MIT NOTICE。涉及商业发行时，再核查整体品牌与素材授权。

## 资源包接口

目前保持 `window.ASSETS = {strip, tiles, count, anims, images}`，世界存档只存方块和物品 ID，不存材质。切换美术不重建世界。`asset-layout.json` 提供兼容的名称与尺寸；后续可以把原创包拆为图集、界面、角色三部分并增加来源清单，避免修改引擎逻辑。
