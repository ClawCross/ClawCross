# 精灵对战与培养

在群聊的 **⋮ → 小程序** 中选择「精灵对战」并启动。手机、桌面和邀请链接中的浏览器使用同一个小程序，无须另装游戏客户端。

## 首页与精灵背包

默认进入浮岛游戏首页。**开始冒险** 会引导新玩家领养第一位伙伴，已有伙伴时进入探索；上方可随时返回首页、打开 **精灵背包**、探索或进入竞技场。可以单人游玩，无须先加入 Agent 或等待另一位玩家。

- **伙伴**：免费选择初始伙伴萤尾、潮团或苔角；管理自己的伙伴，查看生命、攻击、防御、速度和属性。最多保留 12 位野外伙伴。
- **训练**：选择专项训练，消耗星币和体力，增加经验、专项能力与亲密度。点心恢复体力并增加亲密度，休息可免费恢复体力。
- **探险**：与野生精灵回合对战，点击四项技能出招；使用恢复药，削弱对方后使用结契球收服，或随时撤退。获胜可获得经验和星币。
- **成长**：目前等级上限 30。初始伙伴在 3、5、10 级解锁新技能，5、10 级进入新的视觉形态。在伙伴页选择替换的技能槽，保持四项出战技能。
- **物资**：星币通过战斗获得，可用于训练、点心、结契球、恢复药或结识其他初始伙伴。没有付费购买或额外模型调用。

每位群成员拥有独立的伙伴和探险进度。同一成员重新进入可继续，其他成员不能指定一个用户 ID 读取或修改其存档。

## 侧栏精灵设计师

**AI Agent 精灵设计师** 侧栏默认展开，桌面在右侧，手机在下方，可随时收起。在背包点击 **新建精灵**，选择自己带入群聊的 AI Agent，用自然语言描述新伙伴：名字、介绍、原创 SVG 形象、四项技能和动画会一起生成，完成后成为独立的背包精灵。也可以点击 **请设计师改造** 编辑当前精灵。背包中点击四个出战技能可预览其动画，探索战斗也会播放保存的技能特效。

- **设计助手** 与 **玩家聊天** 共用同一个输入框。设计会话只向当前成员显示，玩家聊天保留普通消息和 `@Agent`。
- Agent 回复 `[ClawCrossGame:v1]` JSON 包，可以更新当前伙伴的 SVG、技能与动画，也可打开 `home`、`bag`、`training`、`journey`、`arena` 页面。
- 每个回复绑定本次请求、目标 Agent 与精灵；服务器验证 SVG、技能和数值范围，不执行 Agent 发来的 JavaScript 或任意页面代码。等级、经验、星币保持由游戏管理。
- 设计与动画保存在伙伴存档中，重启后可恢复。设计师工作时仍可浏览游戏；可以取消等待，迟到的设计不会再应用。
- 页面切换和设计消息属于小程序层，使用现有群聊 SDK 调用 Agent，不改变 Agent/Gateway API。

## 玩家竞技场

每位玩家进入竞技场，从 **选择出战精灵** 中选自己的背包精灵，点击 **携带精灵参战**。双方报名后，任一参战玩家可以选择已报名的对手并开始对战；随后轮流点击精灵的四项技能。竞技场不再选择 Agent，不生成新的临时形象，也不需要调用模型。没有 Agent 的玩家也能带初始或捕获的精灵参战。

对局采用背包中保存的形象、技能动画、等级和专项成长；开局后固定，之后的设计和培养不会在半场改变血量。每位玩家只能操作自己的精灵。竞技场结束后向实际参战精灵结算经验和星币，每场只结算一次。旧版已生成的背包精灵仍可选择参战。

## 存档与部署

群主机为小程序提供 `CLAWCROSS_SPACE_DATA_DIR`，SDK 中通过 `space.dataDir` 获取。ClawCross 自动启动和 Hub 官方房间都会按 **群 ID / 小程序 ID** 分配固定目录；成员进度、竞技场设置和对战记录保存在其中的 `state.json`，不放入 Agent 工作区。写入采用临时文件加原子替换，操作带请求 ID 防止重试时重复扣款或发奖。

手动运行时也应指定持久目录：

```sh
CLAWCROSS_SPACE_DATA_DIR=/path/to/private/game-data \
node examples/space-apps/creature-battle/server.js --server http://127.0.0.1:51203 --key '<app key>'
```

首次升级前，旧版竞技场仅保存在进程内，重启会结束旧对局；升级后的存档可在重启后恢复。未指定数据目录的手动 SDK 实例仅保存内存，适合开发。

玩法参考回合制精灵收集游戏；本示例的初始精灵形象、形态与界面均为原创，不包含宝可梦或赛尔号的素材、角色及商标。
