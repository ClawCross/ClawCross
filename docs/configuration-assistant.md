# 配置助手

不需要记住环境变量名。让 Agent 查 `get_configuration`，按说明预填非敏感字段，再用 `request_configuration` 展示私密表单。工具先经 `tool_search` 找到，再通过 `tool_call` 调用。

## 设置范围

| 分类 | 范围 | 生效时间 |
| --- | --- | --- |
| model：内部模型连接 | 主机共用 | 重新加载服务后 |
| voice：语音输出 | 主机共用 | 重新加载服务后 |
| search：TinyFish 连接 | 主机共用 | 重新加载服务后 |
| channel:平台：机器人连接 | 主机共用 | 渠道重新连接后 |
| context：上下文预算与压缩 | 当前 Agent | 下次调用 |
| approval：审核与命令沙盒 | 当前 Agent | 下次工具调用 |
| inference：内部模型思考强度 | 当前 Agent | 下次调用 |

每个字段都提供名称、用途、类型、选项/范围、是否仅允许本人填写。查询私密字段只返回是否已设置，不显示密钥片段。API 地址、程序路径、安全模式也需要本人确认；Agent 不能预填。外部 Codex/Claude 原生模型和模式仍使用其 Agent 设置页。

## 私密填写

用户在对话气泡里的表单填写密钥并保存，浏览器直接提交给已登录后端。密钥不进入聊天、LLM、收件箱或请求登记库。工具只能查询 pending/completed/cancelled/expired；完成通知只包含状态。留空保留已有密钥。

设置助手位于 Studio 设置页。没有网页的渠道请引导用户打开设置页面，不要要求把密钥发在普通聊天中。保存不安装二进制、不调用模型测试、不自动重启主机服务。

## 审批登记

`list_tool_approvals` 现在默认查看当前 Agent 的最近登记和已保存权限，包含审批状态、审核者、KEEP Y 保存是否成功、执行结果与到期时间。可按 pending/approved/denied/used/expired 过滤。

Y 仅批准一次；KEEP Y 保存当前 Agent 的具体操作参数，或命令沙盒的指定网络/文件目标。请求被批准不等于操作执行成功。完整参数可能包含私密数据，登记查询仅显示字段名和参数指纹。保存失败明确拒绝，不静默回退成批准。实际权限仍受工具名单、明确拒绝、沙盒最大范围和严格模式约束。
