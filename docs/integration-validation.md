- 审核决定使用固定测试响应；这些测试验证执行链路，不表示在线审核模型已经实测。

- 页面仍使用原有页面导航，减少首次加载负担；未引入新的 SPA 框架。
- 临时 tunnel 更换域名后，已有远端群成员仍需使用新地址重新加入；本次没有重启在线服务或 tunnel。
- 原始模型快照保留在交接工作树，不进入仓库；仅提交带来源的裁剪目录。启动不自动下载目录或外部项目。
