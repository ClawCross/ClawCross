# 工作区与共享技能

## 工作区选择

默认根目录是 `CLAWCROSS_WORKSPACE_DIR`（通常为 `~/.clawcross/workspace`）。普通 Agent 的工作区是 `users/<用户>/`，同一用户的不同 Agent 共用这个干净目录，用户之间分开。工作区不包含主机配置、审核策略、数据库或 ClawCross 源码；不把源码仓库选为默认工作区。

在当前 Agent 的审核与沙盒设置里选择严格等级后，命令工作区改为 `strict/<用户>/<Agent 哈希>/`，各 Agent 独立，初始权限不变且不能提权。设置本身仍保存在工作区之外。子 Agent 的 isolated/worktree/custom 继续使用已有的独立目录规则。

已有外部 Codex/Claude 原生会话保留自己的原始 cwd，不为了整理工作区重建会话或丢失上下文。ClawCross MCP 命令工具仍按当前用户、Agent 的工作区和沙盒设置执行；外部 CLI 原生工具由自身权限策略约束。

## 技能目录

- 用户共享技能：`users/<用户>/skills/<技能>/SKILL.md`。
- 团队技能：`users/<用户>/teams/<团队>/skills/<技能>/SKILL.md`。
- 同一用户的不同内部/外部 Agent 可通过现有 Memory 工具读取和更新这些技能。按需读正文，动态索引只提供名称简介。
- 普通共享工作区的 command 可以直接访问 skills 及辅助文件。严格命令工作区不自动获得共享目录的文件权限，也不为共享技能放宽沙盒；仍可按现有 Memory 工具读取技能条目。

首次访问时把旧 `user_files/<用户>/skills` 与团队的技能迁入相应工作区，保留 SKILL.md、辅助文件和条目 ID。不移动对话或用户配置。若新旧目录同时存在，只导入缺少的文件，同名文件以工作区版本为准，旧目录冲突文件保留供用户核对，绝不覆盖新内容。

技能文件是 Agent 可读写的任务资料，不是安全策略。审核模式、沙盒最大权限、保存授权及用户凭证继续由工作区之外的后端管理。
